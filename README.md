# AI DOCK

윈도우 작업 표시줄에서 쓰는 Claude Code 실행기 (개인 프로젝트).

- 작업 표시줄 칩: 사용량 게이지, 초기화까지 남은 시간
- 패널: 세션 목록, 채팅, 허락·질문 카드, 차트·카드·표 등 꾸밈 형식
- 세션별 설정 (모델, 권한 모드, 깃 계정, 사진)

## 설치

1. [Releases](../../releases/latest) 에서 `AiDock-win-x64.zip` 을 받아 압축을 풉니다.
2. 폴더 안의 `설치.cmd` 를 두 번 누릅니다.

필요한 것: 윈도우 10 1809 이상 64비트 또는 윈도우 11, [Claude Code](https://docs.claude.com/claude-code), Git for Windows.

서명되지 않은 개인 프로그램이라 처음에 윈도우 경고가 뜰 수 있습니다. 설치 마법사가 안내합니다.

## 알림

- Claude Code 와 Anthropic 의 공식 제품이 아닙니다.
- 소스 코드는 공개하지 않고, 설치 파일만 배포합니다.
